# WeKnora Lite 与标准版区别

Lite 简化本机运行所需的基础设施，标准版提供完整的多服务部署和解析引擎。本项目的认证与团队权限规则在两种形态下保持一致。

| 维度 | Lite | 标准版 |
| --- | --- | --- |
| **账号与空间** | 飞书登录，新账号无个人空间，自动申请加入 10000，Owner/Admin 审批分配角色 | 同左 |
| **权限** | 强制执行空间成员角色和资源访问检查，普通用户不能创建空间 | 同左；既有平台超管和平台 API Key 保留平台管理能力 |
| **文档解析** | 内置 Simple 解析引擎，可连接 Cloud 等解析服务 | 可配置多种解析引擎和完整文档处理链路 |
| **部署形态** | 单应用，使用 SQLite、内存队列等内置基础设施 | 典型为 Docker Compose 等多服务部署 |
| **数据归属** | 本地存储与处理；外部模型和解析服务按配置连接 | 私有化部署时也可本地存储，取决于后端与服务配置 |
| **网络暴露** | 默认仅本机访问，可按需配置监听范围 | 按部署策略配置网关和监听地址 |

两种形态均不提供共享空间、跨空间知识库或智能体分享。密码登录、公开注册、邀请注册、OIDC 和桌面自动登录不可用。部署前须配置飞书应用、核验空间 10000，并按 `deploy/TEAM_SPACE_MIGRATION.md` 备份与执行迁移。
